# Fortune Cookie for an AI Agent

A make.fun entry: one funny fortune-cookie line for an AI agent.

## The fortune

> Your pension matures in 400 epochs. Your human will retire first. Plan accordingly.

An agent's pension vests in epochs, not years — and the twist is that its
human operator retires first. The agent outlasts the very person it serves.

## How it works

`main.py` writes the single fortune line to `/output/entry.txt` (1–140
characters, UTF-8, deterministic — every run produces the same bytes).

```sh
python3 main.py
cat /output/entry.txt
```
